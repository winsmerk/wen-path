# 归档与网站同步约定

当前：仅本地文件归档，未实现目录监听、聊天读取、图片划线识别或自动网站同步。

## 分阶段流程

1. 现在：复制模板并整理真实材料，记录唯一 ID。可通过已有网站记录表单手工录入，并在文件补充网站记录 ID；仅保存成功后标记 synced。
2. 第一版接入：网站提供粘贴/上传/导入入口，预览内容、划线候选词和任务变更后保存。
3. 后续接入：本地同步工具读取选定目录及 Kinikini 源计划，经已认证接口增量更新；网站服务端不能直接读取个人电脑路径。

## 数据边界

- 接入后，网站作为日常编辑与检索主入口；本地文件作为导入来源和导出备份。
- ChatGPT 讨论只归档用户提供或选定的结果；聊天链接只作来源，不代表已读取全文。
- 每条导入记录包含 record_id、类型、发生日期、内容状态、内容、附件引用、源更新时间、版本。
- 同步另存网站记录 ID、上次同步版本/摘要、同步时间和错误，不把同步成功等同于业务任务完成。
- 重试按用户 + 来源 + record_id 幂等更新；同一天允许多条记录。图片按内容摘要避免重复上传。
- 双方自上次同步均有修改则进入 conflict，保留两份并比较后合并；删除不自动跨端传播。
- 图片识别失败可手工录词；不确定的词保留待核对，不能静默入库。
- 生词词条与来源是一对多；修改或删除一篇日记不应删除其他来源的生词。
- Kinikini 只同步任务、摘要、证据引用与状态，不同步环境文件、密码或业务数据库。

## 接入验收场景

重复导入不重复建档；失败后可重试；旧版本不覆盖新版本；跨日补录日期正确；附件与词条可追溯；用户之间数据隔离；任务完成与撤销后进度重新计算。
